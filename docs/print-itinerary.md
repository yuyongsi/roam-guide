# 打印行程与保存 PDF

在“我的行程”中打开自己的行程，点击“打印 / 保存 PDF”。预览读取服务器上已保存的内容，包括行程备忘、每日景点及其备注、时间与交通时长、用餐及备注、行前清单；缩短行程后仍保留的原用餐安排会单独列出。编辑窗口存在未保存内容时，请先保存或关闭该编辑窗口。

预算和预计餐费默认不包含。需要时勾选“包含预算及预计餐费”，等待预览重新加载。点击预览下方的“打印 / 保存 PDF”，在浏览器打印窗口中选择打印机或“另存为 PDF”。打印内容使用 A4 版式，实际分页及页眉页脚取决于浏览器的打印设置。请检查生成文件的内容及分享对象，行程和景点备注、用餐备注都是私人内容。

预览只在本次页面内生成，不会发布到路线广场。行程、时间、用餐以及可选预算由服务器在一次只读事务内组装；接口要求登录并验证行程归属，响应不缓存。预览关闭、登出或账号变化时清除；打印前再次检查登录状态。时间是已有行程设置及景点建议时长计算出的计划，不是实时交通信息。遇到加载失败可切换预算选项重试，或关闭后重新打开。

本轮验证已检查浏览器内的行程预览与预算选项，以及隔离数据库中的接口和前端逻辑；系统打印窗口受到自动安全检查限制，尚未实际完成打印或保存 PDF。因此最终 PDF 分页与浏览器打印窗口仍需在用户环境中确认。
