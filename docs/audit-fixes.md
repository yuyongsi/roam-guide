# 整体审阅问题修复与验收

日期：2026-10-26。原始审阅见项目外outputs/roam-guide-audit-2026-10-26.md，以下记录对应的六项缺陷修复；页内导航、内容丰富等建议没有作为新功能扩展。

## 后台内容与状态

spots/guides新增revision默认1；Database.enrich在迁移早期检查缺列并补充，不覆盖原内容。新建记录使用默认版本，完整编辑先在事务首条写语句中比较版本并递增，之后所有字段、相册、关联景点和元数据同事务保存。验证异常整体回滚。后台spots的gallery从JSON解码为数组，与详情/表单格式一致。

PUT /api/admin/{spots|guides}/{id}要求revision。新增PUT /api/admin/{spots|guides}/{id}/publication，仅接受published布尔值和正版本。SQL只更新published及revision，避免用旧整行数据覆盖标题、正文、相册或关联。未知记录404，已变更409，缺少版本400，权限与CSRF检查保留。

## 身份和草稿

acceptSession集中处理登录、退出、密码更新与会话刷新。身份改变时清空评论草稿；从已登录身份退出或切换时关闭私人弹窗，清理行程、预算、时间、用餐、版本和规划等缓存。匿名进入登录后仍保留待继续的操作。recoverExpiredSession同时识别失效和其他窗口切换账号，重新加载页面；服务器本人权限检查继续独立执行。

## 公开预览与删除

POST /api/me/trips/{id}/publish新增必填trip_revision，和公开路线revision分别检查。事务先锁定本人对应源版本，源行程变化返回409且不建立或更改公开快照。预览刷新重新读取行程及公开状态，保留已经填写的标题/介绍，要求重新勾选公开确认。关闭窗口或身份变化后的迟到响应不会重开旧预览。

DELETE /api/me/trips/{id}新增必填请求体{revision}，使用id+user_id+revision原子删除。旧版本409并保留行程、历史及预算等关联。前端卡片携带当时版本，冲突后只刷新列表，不自动删除新内容；用户需再次确认。当前版本正确删除时原有级联清理保持。版本保护针对行程核心revision，用餐、预算等独立版本仍沿用自身编辑规则。

## 未保存内容

form-safety.js为editDialog/featureDialog中的编辑表单记录初始值，包含复选框、动态攻略小节、相册路径等。原值恢复后不视为改动。关闭按钮和cancel事件统一询问；取消关闭保留原表单。内部导航及浏览器返回可以取消并恢复原页面位置；真正离开网页使用浏览器原生beforeunload提醒。保存成功的程序化close正常关闭，不重复询问。景点查找等筛选表单排除。
