# 停站备份数据

关闭网站启动窗口，等待程序完全退出，然后双击根目录的“备份数据.cmd”。成功后窗口显示备份目录；默认保存在工程所在文件夹旁的“漫游旅行指南数据备份”文件夹。备份包含运行数据目录内的数据库、SQLite 辅助文件、上传图片和私人照片。协调用的 .startup.lock 不属于持久数据，不会复制。请妥善保管：备份可能包含个人信息。

备份期间工具持有与网站相同的数据目录锁，网站使用该目录时会拒绝备份。不要在其他外部程序正在修改数据时备份；锁只协调使用同一锁的网站和备份工具。单独设置 ROAM_LOG_DIR 时，该目录不属于数据目录，不包含在备份内。

可在 PowerShell 中从工程目录使用：

```powershell
powershell.exe -NoProfile -File .\scripts\backup-data.ps1 -DataDir 'D:\网站数据' -Destination 'D:\备份'
powershell.exe -NoProfile -File .\scripts\backup-data.ps1 -Verify 'D:\备份\备份-具体名称'
```

未指定 DataDir 时沿用 ROAM_DATA_DIR，未设置则使用工程内 data；相对路径以工程目录为准。数据目录和目标目录都不能是磁盘根目录；目标目录不能与数据目录互相包含，也不能经过链接或重解析点。每份备份有独立名称，不覆盖旧备份；清单记录文件相对路径、大小与 SHA-256。校验失败或中途出错不会报告备份完成；若出现“未完成”目录，可检查后自行处理。工具检查数据库的 SQLite 文件头，不等于数据库完整性检查；校验只能发现文件与清单不一致，不能证明数据业务内容正确，也不能防止有人同时篡改文件和清单。没有自动恢复功能，恢复前请先另存当前数据并核实备份。
